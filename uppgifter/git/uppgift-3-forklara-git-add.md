# Uppgift 3: Förklara git add

**Poäng:** 5p &nbsp;|&nbsp; **Nivå:** Lätt &nbsp;|&nbsp; **Kategori:** Git

## Att göra

Skriv i lagets README, med **egna ord**, vad `git add` gör. Två till fyra
meningar räcker. Kopiera inte från nätet - poängen är att ni förklarar det
som ni själva förstår det.

Fastnar ni: tänk på att en ändring passerar tre lägen. Först ändrar ni en fil,
sen väljer ni vilka ändringar som ska med, och till sist sparar ni dem i
historiken. `git add` är steget i mitten.

Rättarlaget tittar efter: förklaringen i README-filen i lagets repo.
