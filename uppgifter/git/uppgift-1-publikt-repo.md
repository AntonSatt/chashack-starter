# Uppgift 1: Publikt repo

**Poäng:** 10p &nbsp;|&nbsp; **Nivå:** Lätt &nbsp;|&nbsp; **Kategori:** Git

Laget behöver ett eget repo på GitHub som alla kan jobba i, och som vem som
helst kan öppna utan att logga in.

## Att göra

1. En i laget går till startrepot på GitHub och trycker på **Fork** uppe till
   höger. Det skapar en egen kopia åt laget.
2. Kontrollera att kopian är **Public**, inte Private. Står det "Private"
   bredvid namnet: gå till Settings, längst ner, och byt.
3. Gå till **Settings → Collaborators → Add people** och bjud in alla i laget
   med deras GitHub-användarnamn.
4. Testa: kopiera repots URL, öppna ett privat fönster i webbläsaren och
   klistra in den. Syns sidan utan inloggning är ni klara.

Rättarlaget tittar efter: en repo-URL som öppnas utan inloggning.
