# Uppgift 2: Committa ihop

**Poäng:** 10p &nbsp;|&nbsp; **Nivå:** Lätt &nbsp;|&nbsp; **Kategori:** Git

Alla i laget ska synas i historiken. En commit var, minst.

## Att göra

Varje person i laget gör det här, en i taget:

1. Öppna en fil i repot på github.com och tryck på pennan uppe till höger.
2. Skriv något litet - ditt namn i listan längst ner i den här filen duger.
3. Skrolla ner, skriv ett commit-meddelande som beskriver vad du gjorde,
   och tryck **Commit changes**.

Jobbar ni i terminalen i stället är det de här tre kommandona:

```bash
git add .
git commit -m "beskriv vad du gjorde"
git push
```

När alla har gjort sin commit: gå till fliken **Commits** i repot. Där ska
flera olika namn synas.

Rättarlaget tittar efter: historiken i repot visar commits från flera namn.
