# Frontend (3 uppgifter, 25p)

HTML och CSS. Alla filer öppnas genom att dubbelklicka på dem - ingen server,
inga installationer.

| Uppgift | Poäng | Nivå | Fil |
| --- | --- | --- | --- |
| 1. Rätta buggen | 10p | Lätt | `uppgift-1-ratta-buggen.html` |
| 2. Knappen och rubriken | 5p | Lätt | `uppgift-2-knappen-och-rubriken.html` |
| 3. Egen favicon | 10p | Lätt | `uppgift-3-egen-favicon.md` |

Instruktionerna står överst i varje fil, i den gula kommentarsrutan.

## Bra att veta

- Ser ni inte ändringen? Ladda om sidan med F5.
- Högerklicka på sidan och välj "Inspektera" för att se koden bakom den.
