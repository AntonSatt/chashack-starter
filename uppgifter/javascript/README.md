# JavaScript (3 uppgifter, 45p)

Att få sidan att göra något när man klickar på den.

| Uppgift | Poäng | Nivå | Fil |
| --- | --- | --- | --- |
| 1. Klickräknare | 15p | Medel | `uppgift-1-klickraknare.html` |
| 2. Programmeringsskämt | 5p | Lätt | `uppgift-2-programmeringsskamt.html` |
| 3. Poängtavlan | 25p | Svår | `uppgift-3-poangtavlan.html` |

Alla tre öppnas genom att dubbelklicka på filen. Ta uppgift 3 sist - den bygger
vidare på det ni gjort i uppgift 1.

## Om något inte händer

JavaScript säger inte alltid ifrån när det blir fel. Högerklicka på sidan,
välj **Inspektera** och gå till fliken **Console**. Röd text där betyder att
något är fel - radnumret står till höger.

`console.log(nagot)` mitt i koden är det snabbaste sättet att se vad som
faktiskt ligger i en variabel. Utskriften hamnar i samma Console-flik.
