# Uppgift 1: Deploya sidan

**Poäng:** 20p &nbsp;|&nbsp; **Nivå:** Medel &nbsp;|&nbsp; **Kategori:** DevOps

Att deploya betyder att lägga upp sidan på nätet så att vem som helst kan
öppna den. GitHub gör det gratis åt er.

## Att göra

1. Gå till ert repo på github.com.
2. Klicka på **Settings** i menyn högst upp.
3. Klicka på **Pages** i menyn till vänster.
4. Under **Source**, välj **Deploy from a branch**.
5. Under **Branch**, välj `main` och mappen `/ (root)`. Tryck **Save**.
6. Vänta någon minut och ladda om sidan. Nu ska en URL dyka upp högst upp,
   ungefär `https://anvandarnamn.github.io/repo-namn/`.
7. Öppna URL:en i ett privat fönster för att kontrollera att den fungerar
   utan inloggning.

Ser ni en lista med filer i stället för er sida? Det är helt okej - lägg till
`/uppgifter/frontend/uppgift-2-knappen-och-rubriken.html` på slutet av URL:en
så kommer ni till sidan.
