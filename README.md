# ChasHack-starter

Startpunkten för ert lag på ChasHack.

1. Forka det här repot: knappen **Fork** uppe till höger.
2. Klona er fork: den gröna **Code**-knappen ger er URL:en.
3. Öppna `index.html` i webbläsaren och bygg vidare: `index.html`,
   `style.css` och `script.js` är era arbetsfiler.

Skelettet har tips i kommentarerna. Lämna in repolänken till er fork på
ChasHack-sidan, en inlämning per lag.
