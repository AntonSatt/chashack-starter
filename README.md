CookieRookies 🍪

CookieRookies är en enkel hemsida skapad med HTML, CSS och JavaScript.

På sidan kan man:

- Se CookieRookies logotyp
- Klicka på logotypen för att komma till YouTube
- Se medlemmarna i gruppen
- Klicka på varje namn för att få en liten hälsning
- Se en footer längst ner på sidan
